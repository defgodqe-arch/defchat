Enable live registration

The repository workflow is prepared for DNSHE's domain API. The repository owner must create a DNSHE account, confirm that de5.net is available to that account, and add DNSHE_API_KEY and DNSHE_API_SECRET under GitHub repository Settings → Secrets and variables → Actions. Requests must be reviewed and labeled domain-approved before the workflow registers them.
