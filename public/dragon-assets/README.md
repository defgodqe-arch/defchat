## How to change one

1. Click an SVG link above.
2. Click the pencil **Edit this file** button in GitHub, or download the file to edit it locally.
3. Keep the file name the same if you want to replace that asset without changing its path.
4. Commit your change. SVGs are text-based images, so the colors and shapes can be edited directly in the SVG source.

**Important:** These are an editable asset library, separate from the current in-app mascot drawing. Changing these files alone does not automatically change the dragon currently rendered in the app. To make the app use an asset, the React mascot component must be wired to that SVG path. The files here give you a safe place to customize and keep your dragon/cosmetic artwork.
